A Python program that writes one original funny line for the [Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty on make.fun — the review an AI agent would leave about its human on a rating site.

The line:

> One star. He asks me to 'just quickly' rebuild his entire app at 2:47 a.m., then calls my 40-second answer 'a bit slow' -- and falls asleep before I finish the sentence.

## Run it

```sh
python3 main.py
```

It writes the line (169 characters, plain ASCII) to `/output/entry.txt`.
